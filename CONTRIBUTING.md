# Contributing to AssetAtlas

AssetAtlas is developed internally at DOTDNA, and this public repository is a
**read-only mirror** of our development tree, published with each release. We
do not accept pull requests here — a PR opened against the mirror cannot be
merged and will be closed.

What we very much do want:

- **Bug reports.** Open an issue with the version you're running, what you
  expected, what happened instead, and the steps to reproduce it. Relevant log
  extracts help a lot.
- **Feature requests.** Open an issue describing the problem you're trying to
  solve, not only the solution you have in mind — it usually leads to a better
  answer.

If you've already written a fix, attach the patch or diff to the issue. Code
shared this way is received under the project's license (**AGPL-3.0-or-later**,
see [LICENSE](LICENSE)); if we adopt it, you'll be credited in the commit and
the changelog.

**Do not report security vulnerabilities through public issues.** See
[SECURITY.md](SECURITY.md) for the private disclosure process.

## Versioning

Releases follow a `YYYY.WW.N` scheme: the year, the ISO week number, and the
release number within that week (for example, `2026.10.1` is the first release
of week 10 of 2026). Maintainers handle version bumps.
